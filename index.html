Self Car

This is a program that allows you to train cars so that, with limited perception of the track, they can learn to drive using neural learning.

Download Self Car

How to run

  1. Download the ZIP file.
  2. Extract the ZIP file.
  3. Open the extracted folder.
  4. Run the .exe file.
  5. Watch training process!
Windows Security warning:
If Windows shows a blue window saying that it protected your PC, click More info, then click Run anyway.

Platform: Windows only.
